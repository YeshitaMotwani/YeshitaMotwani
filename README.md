## ✦ Featured Projects

### 🤖 AutoStartup Simulator
**Multi-Agent GenAI Workflow**   ![Active](https://img.shields.io/badge/Active-ff6eb4?style=flat-square)
> *An autonomous AI workforce orchestrating business generation.*
- **4-Agent LangGraph Architecture** (CEO, CMO, CFO, CTO)
- Implemented state tracking and conversational memory for multi-step reasoning.
- Tool-calling integration to generate PPT pitch decks via Python scripts.
- **React.js frontend** with live execution logs.
- *Tech Stack:* `Python`, `LangGraph`, `React.js`, `Tool Calling`

### ⚙️ Agent Distillation Compiler
**LLM Fine-Tuning & Evaluation**   ![Completed](https://img.shields.io/badge/Completed-c77dff?style=flat-square)
> *Training smaller models to code like massive multi-agent systems.*
- Fine-tuned **Qwen2.5-Coder-7B** using 4-bit **QLoRA** and rank-8 adapters.
- Evaluated automated code generation achieving **88.2% pass@1**.
- Built a complexity router with **70.4% accuracy** for optimized inference latency.
- *Tech Stack:* `Python`, `Qwen2.5`, `PyTorch`, `QLoRA`, `FastAPI`

### 🛡️ SWARN: Multi-Agent RL Benchmark
**DIAT, DRDO Research Internship**   ![Research](https://img.shields.io/badge/Research-7b61ff?style=flat-square)
> *Jamming-resilient drone swarm navigation algorithms.*
- Developed reproducible RL benchmark evaluating **7 algorithms across 12 configs**.
- **MADDPG** achieved 92.4% mean coverage.
- Evaluated a KL-Anchored Navigator improving drone-swarm detection under jamming from **42.5% to 55.5%**.
- *Tech Stack:* `Multi-Agent RL`, `PyTorch`, `QMIX`, `PPO`, `Defence AI`

### 🎙️ StutterFix: Neural Speech Remediation
**Speech AI Framework**   ![Active](https://img.shields.io/badge/Active-ff8de3?style=flat-square)
> *Giving machines the precision to hear what's wrong — and fix it in milliseconds.*
- Fine-tuned **Wav2Vec 2.0** (SEP-28k) · detection threshold **0.93**.
- Millisecond-precision excision at **16kHz**.
- Whisper-based Silver Standard · **WER < 0.15**.
- Noise-robust validation: **5–25 dB SNR bins**.
- *Tech Stack:* `Python`, `Wav2Vec 2.0`, `Whisper`, `LPC`, `TensorFlow`
