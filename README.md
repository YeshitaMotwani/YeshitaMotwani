*January 2026 – Present*

> Fine-tuned **Wav2Vec 2.0 Transformer** (SEP-28k) for stutter detection (threshold: 0.93) with millisecond-precision audio excision on 16kHz speech for real-time remediation. Acoustic + linguistic evaluation via **12th-order LPC** (LLR, ISD) and **Whisper-based Silver Standard** (WER < 0.15); validated across 5–25 dB SNR bins with MOS (n=40).

`Wav2Vec 2.0` `Speech Processing` `LPC Analysis` `Whisper` `Signal Processing` `Transformer`

`ResNet-18` `Psychoacoustics` `Deep Learning` `GPS Mapping` `Gradio`
